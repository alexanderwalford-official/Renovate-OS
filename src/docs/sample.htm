HTML in the AerOS reader

This page is plain HTML, the language web pages are written in. The reader turns its tags into the same headings, lists and colours it uses for Markdown, so the two look alike on screen.

Text

Words can be strong, emphasised or code. Characters like <, > and & are written with entities.
A <br> starts a new line without a gap.

A blockquote is shown with a bar down its side, like a quote in Markdown.
